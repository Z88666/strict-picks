## v3 联网查新品 — 按“搜了才查”做的

- **搜不到就自动查：** 本地 0 结果时 0.8 秒后自动联网查，不用再点一次；也可以点“联网查这个产品”手动查。
- **查什么：** 维基百科 + DuckDuckGo + 代理抓取三路并行（8 秒超时），显示摘要、文中提到的 ¥ 价格、红线词扫描，再加京东 / 淘宝 / 拼多多 / 什么值得买四张实时比价卡。
- **硬筛选：** 品牌力（内置大品牌表，只认大品牌）、价格区间（你设最低/最高价）、配料/材质绝对前提。没有完整配料表就只能算“待核实”，不能算通过；有红线词直接淘汰。
- **粘贴配料表自动评分：** 从平台页面复制配料表粘进来，自动数种数、扫红线词，给分给结论，存为“待核实收藏”，跟正式库分开。
- **诚实说明：** 淘宝/京东/拼多多没有公开免费比价接口，维基百科结果有时关联弱（如搜洗面奶会带出乾酪），代理有时不可用。联网结果是摘要，不是已核实入库；实时价以打开的平台页为准。

## 平台与刷新 — 按你的要求做的

**淘宝 / 天猫 / 京东 / 拼多多，四平台都比了。** 每款都写了各平台价和“最低价平台”，不是只写一个价。

**手动刷新：** 打开网站点右上角「↻ 手动刷新最新数据」，会重新拉取 `data/products.json`（带时间戳防缓存），拉到新版就显示更新时间，拉不到就明确告诉你“仍用内置快照”，不会假装刷新了。

**为什么不是实时爬淘宝/拼多多：** 淘宝、拼多多、京东都没有公开免费比价接口，公开爬取会被反爬封掉，价格也是券后实时变的。所以本站的做法是：本站数据文件是核实过的快照（可更新）+ 每款下面有「京东搜 / 淘宝搜 / 拼多多搜」一键链接，点开就是该平台实时搜索结果，下单前以实时页为准。这是最诚实、不会断链的做法。

**收藏：** 点每款的「☆ 收藏」，存在本机（localStorage），关掉重开还在；勾「只看我的收藏」就能只看收藏的。

## 硬标准

- **食品：** 配料≤6种、0防腐剂/甜味剂/味精/焦糖色/增味剂、酱油氨基酸态氮≥0.8（特级）、非转基因、酿造工艺。
- **衣服：** 绒子含量≥90%、蓬松度≥600、羊毛/棉100%才算通过；牛仔裤82%棉只能算慎选。
- **住行：** 保温杯316不锈钢、行李箱纯PC、被子绒子含量≥90%、床垫独立袋装弹簧。
- **价格：** 2026-11-10 京东/天猫/拼多多检索快照，券后价波动大，下单以实时页为准；配料/材质以包装吊牌为准。
